Instalação¶

Requisitos¶

  • Python >= 3.10
  • Django >= 5.2

Via pip¶

Instale o pacote diretamente do PyPI:

pip install django-auth-govbr

Via poetry / uv¶

uv add django-auth-govbr
# ou
poetry add django-auth-govbr
